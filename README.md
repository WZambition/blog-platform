# 星语博客平台

一个基于 **Vue3 + Element Plus + Spring Boot** 的全栈博客系统，包含两大核心模块：

1. **AI 观点星空**：每个人都可以发表自己的观点，观点像星星一样在夜空中闪烁。点击任意一颗星星，观点就会转化为一个议题（讨论区），大家可以围绕它展开讨论。
2. **技术讨论区**：以卡片形式展示技术问题（上方配图、下方描述）。支持问题发布、方案提交、方案修改、状态流转（未解决/验证中/已解决）以及消息提醒。

## 快速启动

### 环境要求
- JDK 17+
- Maven 3.6+
- Node.js 18+

### 1. 启动后端

```bash
cd backend
mvn spring-boot:run
```

后端默认运行在 `http://localhost:8080`，H2 控制台地址 `http://localhost:8080/h2-console`。

### 2. 启动前端

```bash
cd frontend
npm install
npm run dev
```

前端默认运行在 `http://localhost:5174`，已配置代理将 `/api` 请求转发到后端 8080 端口。

> **注意**：前端使用 **5174** 端口（而非常见的 5173），因为 5173 可能被 workSwarm 网页版占用。若需修改端口，请编辑 `frontend/vite.config.js` 中的 `server.port`。

### 3. 访问系统

打开浏览器访问 `http://localhost:5173`。

## 功能清单

### 用户模块
- 用户注册 / 登录
- 游客登录（无需注册，输入昵称即可进入）
- 用户信息展示

### AI 观点星空模块
- **发布观点**：填写标题和内容，选择星星颜色，观点生成一颗星星
- **星空展示**：观点以彩色星星形式在深空背景中闪烁，可自定义颜色和位置
- **点击成议题**：点击任意星星，观点转化为议题（讨论区）
- **议题讨论**：在议题下发表看法，参与讨论
- **点赞**：支持对观点点赞

### 技术讨论区模块
- **卡片展示**：技术问题以卡片形式展示，上方配图、下方问题描述
- **状态筛选**：按未解决 / 验证中 / 已解决筛选
- **发布问题**：填写标题、描述、配图 URL、标签
- **提交方案**：他人可为问题提交解决方案
- **修改方案**：方案作者可修改自己的方案
- **状态流转**：
  - 问题发布 → **未解决**
  - 收到方案 → **验证中**（自动流转）
  - 采纳方案 / 标记解决 → **已解决**
  - 验证不通过 → 可重新标记为**未解决**
- **采纳方案**：问题发起者可采纳某个方案，问题标记为已解决

### 消息提醒模块
- **新方案提醒**：当别人给问题发起者提交方案时，自动给发起者发送消息提醒
- **方案采纳提醒**：方案被采纳时，通知方案提交者
- **未读计数**：导航栏显示未读消息数
- **消息中心**：查看所有消息，支持单条已读和全部已读

## 核心业务逻辑说明

### 技术问题状态流转

```
发布问题 ──→ 未解决(UNSOLVED)
                │
                │ 他人提交方案
                ▼
            验证中(VERIFYING) ──→ 发起者采纳方案 / 标记解决
                │                        │
                │ 发起者标记未解决        ▼
                ▼                    已解决(SOLVED)
            未解决(UNSOLVED)
```

### 消息提醒触发时机

| 触发动作 | 接收者 | 消息类型 |
|---------|--------|---------|
| 他人提交方案 | 问题发起者 | NEW_SOLUTION |
| 方案被采纳 | 方案提交者 | SOLUTION_ACCEPTED |

## 数据模型

| 实体 | 说明 |
|------|------|
| `User` | 用户 |
| `AiOpinion` | AI 观点（星星），含位置、颜色、大小、是否议题化 |
| `OpinionComment` | 观点议题下的讨论 |
| `TechQuestion` | 技术问题，含状态（UNSOLVED/VERIFYING/SOLVED） |
| `Solution` | 技术问题方案，含是否被采纳 |
| `Notification` | 消息提醒 |
